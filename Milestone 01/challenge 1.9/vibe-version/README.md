# Vibe Version

This folder contains the task manager app built using a vibe coding tool.

**Tool used:** Antigravity (simulating v0 / Lovable)
**Time to generate:** ~30 seconds
**Prompt used:** "Build a simple Task Manager. Features: add task via input + Add button or Enter key; click task to toggle complete with strikethrough; three filter buttons: All, Active, Completed; show 'X tasks remaining' count. Single HTML page, no backend. Make it look beautiful and modern."
**Live URL:** Local Deployment Ready (Pending upload to Netlify/Vercel)

## Notes
The tool successfully generated a single-file application using Tailwind CSS for styling and Vanilla JavaScript for logic. It looks modern, feels responsive, and perfectly implements the required feature set without requiring complex build steps.
